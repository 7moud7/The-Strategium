exist here, the app falls back to the direct Higgsfield CDN links baked into
`App/thestrategium.html` (the `ART_OVERRIDES` map).

To make the artwork permanent, download each URL below, save it with the given
filename in this folder, commit, then delete the entries in `ART_OVERRIDES`:
